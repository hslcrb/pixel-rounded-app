# 테스트 계획과 실행 증거

## 현재까지 검증

2026-10-26 기준 GitHub에 푸시한 `filters.js`, `matcher.js` 코드를 다시 읽어 **V8 함수 환경에서 독립 테스트 하네스**로 검증했습니다.

- 필터 코어 10개 테스트: 통과 10, 실패 0
- 전후 이미지 매칭 5개 테스트: 통과 5, 실패 0
- 메인/프리로드/렌더러/엔진 JavaScript 문법 검사: 통과
- HTML에서 참조하는 DOM ID 존재 여부 확인: 통과
- 샌드박스/IPC/protocol 관련 코드 존재 여부: 확인
- Figma 데스크톱 편집기 시안 스크린샷 생성 및 시각 확인

**중요:** 이 결과는 **실제 Electron GUI 실행이나 Node.js `npm test` 명령 실행 증거가 아닙니다**. 테스트 스크립트를 프로젝트에 포함했으므로 로컬에서 별도 검증하세요. 인터넷이 막힌 실행 환경에서 electron 바이너리를 설치하거나 Windows 빌드를 수행하지 못했습니다. 실사 사진 다운로드/실제 포맷 통합 테스트는 아래 계획으로 남겨 둡니다.

## 개발자 재현

```sh
npm install
npm run check
npm test
npm start
```

윈도우 패키징: `npm run dist:win`. 단, 툴체인 다운로드와 플랫폼별 추가 도구가 필요할 수 있습니다.

- [ ] 대용량 파일과 파손 데이터 오류 처리가 적절함

- [ ] 좌/우 비교 핸들 드래그 및 방향키 조작
- [ ] 300% 확대 후 격자 표시와 픽셀 RGB 읽기
- [ ] Undo/Redo와 Reset 기능

- [ ] PNG 투명도와 JPG 배경색 확인
- [ ] 원본 해상도 저장과 파일 무결성 확인
- [ ] Mac/Linux 등 대상 플랫폼 실행 시 폰트 폴백과 화면 레이아웃 확인
- [ ] 네트워크 차단 상태에서 편집·저장 성공

## 알려진 제한

24MP 이미지의 저장 단계는 메모리를 많이 사용합니다. EXIF 메타데이터/ICC 프로필을 보존하지 않으며 JPG 출력은 기본 92% 품질로 재압축됩니다. 사진 구도 불일치에 대한 자동 정합 기능은 없습니다.

## 릴리스 통과 조건

위 수동 체크가 완료되고 실제 OS/버전/빌드 SHA가 기록되어야 공개 바이너리를 안정 릴리스로 취급합니다. 실행하지 않은 테스트는 '통과'로 표시하지 않습니다.
