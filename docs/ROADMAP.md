# Roadmap · 픽셀의 다음 계절

## 0.1.x — 기초 사진 연구소

- [x] Electron 오프라인 데스크톱 앱 골격
- [x] 전후 비교 캔버스와 프리셋
- [x] 색·빛·필름·픽셀 모자이크 필터
- [x] 좌표별 RGB와 톤 분류
- [x] 동일 장면 참조 사진에서 전역 톤 파라미터 근사
- [x] 자체 라이선스 및 에이전트/사람 협업 문서
- [ ] 실제 Electron GUI, 실사진 테스트 및 Windows 패키징
- [ ] 코드 서명, 의존성 잠금 파일, 릴리스 체크섬

## 0.2 — 사진다운 필름

- [ ] 채널별 커브, HSL, 색상별 분할 톤
- [ ] 다중 스케일 Bloom 및 Halation
- [ ] 이미지 부분 마스크와 브러시
- [ ] EXIF 방향 처리, ICC 프로필 인식
- [ ] 웹 워커/OffscreenCanvas로 UI 스레드 분리
- [ ] 프리셋 JSON 가져오기·내보내기

## 0.3 — Photo Craft Studio

- [ ] 같은 장면 자동 정렬 / feature matching
- [ ] Pixel-region 분석 및 국소적 필터 추정
- [ ] 정밀 LUT 생성, ColorChecker 검증
- [ ] 배치 처리와 필터 이력 관리
- [ ] 플러그인 인터페이스와 성능 벤치마크

## 장기 원칙

무리한 AI 명칭보다 재현 가능하고 소유권이 명확한 기술 구현을 우선합니다. 프리셋 성능은 외부 저작권 대상 사진을 무단 학습하거나 외부로 전송하지 않고 연구합니다.
