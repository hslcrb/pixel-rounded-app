# pixel-rounded · Brand Identity ♡

## 이름의 뜻

pixel-rounded: **둥글게 다듬어진 픽셀**, 보다 부드럽고 아름답게 변화하는 이미지. 계산 가능한 정밀함과 사진을 보는 사람의 온기를 동시에 의미합니다.

**English tagline:** Make every pixel feel.  
**Korean voice:** 픽셀 하나하나에 감각을 더하다.

## 브랜드 철학

- **Soft technology:** 도구는 강력하지만 표정은 다정하게.
- **Local-first:** 사진은 사용자의 소중한 데이터. 서버 업로드 없는 처리.
- **Craft over complexity:** 복잡한 편집 기능을 한눈에 이해할 수 있는 언어로.
- **Researchable creativity:** 예쁜 필터가 왜 예쁜지 픽셀/색채 기법 문서로 설명.
- **Humble precision:** 기계학습·물리적 광학·정확한 색보정 같은 말을 구현 이상으로 주장하지 않기.

## 로고 원칙

2×2 네 개의 11px 코너 라운드 픽셀: 라벤더/피치 대각 배치. 원본 SVG 자산은 `src/assets/logo.svg`를 사용합니다. 네 칸의 틈은 **데이터와 감성, 전과 후, 사람과 기술** 사이의 여백을 상징합니다.

## 인터페이스

- 한 창에서 전/후 비교가 가능하고 별도 모달 없이 필터와 조절을 사용합니다.
- 격자, 픽셀 좌표, 색상 코드가 실제 분석 도구 역할을 합니다.
- 토스트 메시지는 짧고 가볍되 실패 원인은 명료해야 합니다.
- 시각 효과는 사용자 조작을 방해하지 않아야 합니다.
- 키보드 포커스, 대비, aria-live 텍스트를 제공합니다.

## 타이포그래피와 에셋

한글 시스템 폰트(Pretendard 설치 시 우선, Wanted Sans 설치 시 대체, 시스템 기본 폰트)와 Inter 계열 미려한 이미지가 기본 방향입니다. 폰트 파일은 별도 권리를 확인하기 전 저장소에 포함하지 않습니다.
