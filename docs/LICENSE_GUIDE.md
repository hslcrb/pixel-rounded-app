# 라이선스 운영 안내

> PR-SAL-1.0 · 자체 소스 공개 라이선스 **초안** (전문 법률 자문 미진행)

## 핵심 구별

pixel-rounded는 코드를 읽고, 연구하고, 공식 프로젝트에 기여할 수 있도록 공개합니다. 그러나 **재배포·상업적 사용·독립 파생 앱 공개는 제한**합니다. 따라서 **OSI 기준 오픈소스가 아닌 source-available(소스 공개형)** 소프트웨어입니다.

| 용도 | 일반 허용 |
|---|---|
| 소스 열람과 학습 | ✅ |
| 비상업적 개인 실행, 내부 평가 | ✅ |
| 개인·비공개 수정 | ✅ |
| 공식 프로젝트 기여용 GitHub Fork 및 PR | ✅ |
| 외부 미러링, 타 플랫폼 바이너리 배포 | ❌ |
| 별도 앱 제작, 유료 서비스 제공 | ❌ |
| 로고·브랜드 도용 | ❌ |
| 사용자 자신의 이미지 편집·출력 | ✅ (원본 권리 존중) |

소스 공개 라이선스는 **무단 사용에 대한 허락 범위를 계약적으로 정하는 방법**이지, 온라인 유출이나 저작권 침해를 기술적으로 완벽하게 차단하는 장치가 아닙니다. 관할 국가와 권리자의 법적 지위 등에 따라 조항 집행 가능성이 달라질 수 있습니다.

## 기여자의 권리

PR 작성자는 자기 기여물에 대한 저작권을 유지하지만, LICENSE 제4조에 따라 프로젝트 유지관리자에게 해당 기여를 수정·배포·재라이선스할 수 있는 비독점적 권리를 부여합니다. 동의하지 않는 코드를 제출하지 마세요.

## 권리 출처

- Electron, electron-builder 및 하위 의존성은 별도 라이선스를 따릅니다.
- 브랜드 심볼과 내장 데모 SVG는 이 프로젝트를 위해 작성한 자산입니다.
- 외부 사진은 별도 라이선스를 확인한 **테스트 참고 링크**만 사용합니다. 사진 바이너리를 이 라이선스로 재포장하지 않습니다.
- 소프트웨어로 편집한 사용자 사진과 출력물의 소유권을 주장하지 않습니다.

정식 출시나 유료 배포 전에는 법률 전문가와 라이선스·기여 동의·상표 사용 정책 등을 검토하는 것이 좋습니다.

## 오픈소스 전환을 원한다면

OSI 인정 라이선스(MIT, Apache-2.0 등)를 선택하면 자유로운 수정·재배포를 허용해야 합니다. 원칙적으로 **OSI 오픈소스와 일반적인 재배포 금지는 동시에 달성할 수 없습니다.** 프로젝트 목표 변경 시 문서와 파일 전체를 함께 업데이트해야 합니다.
