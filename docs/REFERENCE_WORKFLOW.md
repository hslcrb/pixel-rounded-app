# 사진 전후 레퍼런스로 필터 만들기 📷

## 목표

같은 장면을 찍은 **원본 Before**와 **원하는 결과 After** 두 장을 보고, 픽셀 값을 정량 비교하여 비슷한 색감의 편집 설정을 자동 제안합니다. 원본·결과 사진을 픽셀 단위로 분석하는 과정을 문서화합니다.

## 사용 순서

1. 앱에서 **사진 열기** 또는 파일 드래그 앤 드롭으로 원본 사진을 불러옵니다.
2. 오른쪽 **전후 사진으로 필터 만들기 → 완성 사진 가져오기**를 누릅니다.
3. 같은 장면의 완성본 이미지(PNG/JPEG/WebP)를 선택합니다.
4. 엔진이 사진의 비율을 검사하고 미리보기 치수에 맞춰 정렬합니다.
5. 최대 82px 길이의 표본에서 이미지 픽셀 RGB 제곱 오차를 계산합니다.
6. 6가지 전역 조정값을 탐색해 오차를 줄이는 결과를 고릅니다.
7. 오차 감소율·표본 수·중간톤 RGB 변화량을 표시하고, 제안된 설정을 슬라이더에 적용합니다.
8. 비교 핸들을 움직여 결과를 본 뒤 블룸·입자·둥근 픽셀 등을 수동으로 추가합니다.
9. PNG 또는 JPEG로 **원본 해상도** 내보내기 합니다.

## 예시: 서로 다른 사진은 왜 어려울까?

- 피사체가 다르면 동일 좌표의 픽셀이 비교 가능한 대상이 아닙니다.
- 크기만 맞춘다고 정렬이 완벽해지지는 않습니다.
- 원근 변형, 시간차, 물체 이동, 조명 변화가 크면 색감 최적화가 실패하거나 엉뚱한 파라미터를 제안합니다.
- 현재 자동 정렬·광학 흐름·객체 분할·피부 보존·LUT 추정·세그멘테이션 AI는 제공하지 않습니다.

## 픽셀 단위 기록 포맷

| 지표 | 의미 |
|---|---|
| X/Y | 원본 사진 기준 좌표 |
| RGB HEX Before/After | 미리보기에서 같은 위치의 채널값 |
| Tone | 원본의 그림자 / 중간톤 / 하이라이트 |
| ΔRGB | 각 영역에서 참조 후−원본의 평균 채널 변화 |
| MSE | RGB 채널 오차의 제곱 평균 |
| 오차 감소 % | 전역 보정 추정 전/후 MSE 감소비 |

최적화는 기계학습 훈련이 아닌 **규칙 기반 수치 최적화**입니다.

본인이 촬영했거나 사용·가공 권한이 있는 사진만 사용하세요. 공개 전후 사례에는 촬영자, 출처, 공개 권한, 필요시 피사체 동의를 남기세요. 프로젝트는 사용자 사진을 자동 전송하지 않고, 기본 테스트용 내장 SVG는 직접 작성했습니다.
