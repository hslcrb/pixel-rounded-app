# 사진의 기술 · Photography Notes 🌤️

> 아름다운 사진은 밝기 수치의 조합만으로 정의할 수 없지만, 픽셀마다 어떤 변화가 일어났는지 설명할 수는 있습니다.

## 1. 노출 (Exposure)

카메라에서는 셔터·조리개·감도에 따른 광량을 이야기합니다. pixel-rounded의 노출 슬라이더는 이미 찍힌 sRGB 이미지의 RGB 값에 `2^(exposure/100)`을 곱합니다. 이는 **후처리상의 유사 노출**이지 실제 RAW 노출 복원이 아닙니다. 하이라이트가 이미 255로 잘렸다면 복구하지 못합니다.

## 2. 대비 (Contrast)

중간 회색값 127.5를 기준으로 각 채널을 늘리거나 줄입니다.

- 양수: 밝은 부분과 어두운 부분을 벌림
- 음수: 차이를 좁혀 부드러워짐
- 명암 영역마다 별도 곡선을 다루는 고급 Curves 기능과는 다름

## 3. 채도와 색온도

채도는 상대 휘도 `L = 0.2126R + 0.7152G + 0.0722B`로부터 RGB 채널의 거리를 확대/축소합니다. -100에서는 무채색 결과를 냅니다. 색온도는 빨강을 높이고 파랑을 낮추거나 그 반대 방식으로 시각적 온기를 모사합니다. Kelvin 수치나 ICC 색온도 변환에 일치하지 않는 **창작형 조절**입니다.

## 4. 블룸 · 빛 번짐

렌즈 주변의 빛이 퍼져 밝은 부분에 보드라운 광택을 주는 느낌. 현재 엔진은 3×3 인접 샘플의 밝은 부분을 모아 가산하는 빠른 근사 구현입니다. 물리 기반 광학 PSF나 다중 반경 Gaussian blur와 동일한 결과가 아닙니다.

## 5. 필름 입자 (Grain)

픽셀 좌표 (x, y) 및 정수 seed를 해시해 동일한 사진과 필터 입력이 항상 동일한 입자를 얻습니다. 예측 가능하고 테스트하기 쉽습니다. 실제 필름 스톡의 입자 크기나 색별 구조를 완전히 모사하지는 않습니다.

## 6. 비네팅 · 바랜 필름

비네팅은 중심에서 가장자리로 멀어질수록 빛을 줄입니다. Fade는 어두운 부분의 채널을 들어올리고 흑색을 살짝 부드럽게 만듭니다. 눈에 보이는 결과의 감성적 차이를 비교하면서 사용하세요.

## 7. 둥근 픽셀 · Rounded Pixels

사진을 정사각형 셀로 나누어 각 셀의 색상 평균을 계산한 다음, 라운드 사각형 마스크로 출력합니다. 모서리 바깥은 원래 픽셀을 어둡게 남겨 셀 사이에 자연스러운 간격을 만듭니다.

- Pixel Size 0: 가공하지 않음
- Pixel Size 증가: 블록 단위로 색을 요약
- Roundness 증가: 사각형이 둥근 모양으로 변함
- 투명도(alpha)는 입력 그대로 보존

## 8. 픽셀 색영역 구분

한 픽셀의 대략적 휘도 분류:

| 밝기 L | 분류 |
|---|---|
| 0–84 | 그림자 |
| 85–181 | 중간톤 |
| 182–255 | 하이라이트 |

RGB 최대–최소 범위가 20 미만이면 무채색, 빨강–파랑 차이가 38 초과면 따뜻한 색, 반대면 차가운 색으로 구분합니다. 이것은 간단한 **규칙 기반 설명**이며 AI/신경망 분류가 아닙니다.

## 9. 사진의 전과 후로 기법을 연구하기

동일 장면의 원본과 완성본을 같은 크기·방향으로 정렬하고, 중간톤·그림자·하이라이트의 채널 차이를 측정하세요. 색감·명암의 경향을 찾은 뒤, 노출·대비·채도·색온도 등 전역 파라미터를 조정합니다. 현재 앱은 이 작업의 일부를 자동화합니다. 자세한 절차: [전후 사진 연구](REFERENCE_WORKFLOW.md).

## 10. 정확성의 한계

현재 버전은 sRGB 8bit 채널에서 작업하며 장치 ICC 프로필, HDR, RAW, 광학적 노이즈 모델, 고급 디모자이킹, 얼굴별 마스크, 실시간 GPU 처리, 인물 피부톤 보호, 차등 프레임 정렬을 구현하지 않습니다. 해당 사항은 이후 연구 과제입니다.
