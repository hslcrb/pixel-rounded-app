# 배포 및 검증 가이드

## 개발 실행

```sh
npm install
npm run verify
npm start
```

최초 설치에는 네트워크 연결이 필요합니다. 앱 내부의 사진 편집은 오프라인에서 진행됩니다.

## Windows

```sh
npm run dist:win
```

프로젝트는 electron-builder의 portable EXE와 NSIS 설치파일을 목표로 설정했습니다. Windows 호스트 또는 지원되는 크로스 빌드 환경에서 바이너리/설치파일이 실제 만들어지는지 확인해야 합니다. 크로스 빌드 요구 도구와 코드 서명은 호스트마다 다를 수 있습니다.

## Linux

```sh
npm run dist:linux
```

AppImage 빌드 설정을 포함했습니다. 실제 시스템 패키지 준비가 필요할 수 있습니다.

## 출시 전 절차

1. 잠금 파일을 생성하고 버전/의존성 취약점을 점검합니다.
2. `npm run verify` 및 GUI 사진 편집·내보내기 테스트를 완료합니다.
3. CC0 또는 직접 제작한 합법적인 사진으로 실제 JPEG/PNG/WebP 테스트를 합니다.
4. 유효한 아이콘(.ico/.icns), 앱 버전, 서명 정책을 마련합니다.
5. 빌드 아티팩트 SHA-256, OS, 실행한 명령어, 생성 결과를 기록합니다.
6. PR 통합 후 별도 승인을 거쳐 GitHub Releases에 파일을 올립니다.

## 현재 상태

GitHub에 소스 파일이 반영된 것은 배포 가능 바이너리가 만들어졌다는 의미가 아닙니다. 이 환경에서는 인터넷을 통한 npm 의존성 설치 및 윈도우 GUI 검증을 실행하지 못했습니다. **0.1.0은 소스/기능 검토 단계**입니다.
